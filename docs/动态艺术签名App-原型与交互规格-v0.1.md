## 1. 视觉基调

App 皮肤支持 **深色 / 浅色 / 跟随系统** 三种，默认「跟随系统」。
⚠️ 关键：**UI 主题与作品画布背景解耦** —— 换皮肤不能影响导出效果，否则浅色皮肤下会误判配色。

### 1.1 深色（作品感最强，演示/夜间默认观感）

| Token | 值 | 用途 |
| --- | --- | --- |
| `bg` | `#121214` | 页面背景 |
| `panel` | `#1C1C20` | 卡片、参数面板 |
| `stroke` | `#2A2A30` | 分割线、卡片描边 |
| `text` | `#F2F0EA` | 主文字（带一点暖调，像宣纸） |
| `textDim` | `#8A8A94` | 次要文字、说明 |
| `accent` | `#C62828` | 强调色（朱红，印章同色系） |
| `ok` | `#3BA55D` | 成功 |

### 1.2 浅色（白天 / 打印预览 / 长辈用户）

| Token | 值 | 用途 |
| --- | --- | --- |
| `bg` | `#FAF8F3` | 页面背景（宣纸白） |
| `panel` | `#FFFFFF` | 卡片、参数面板 |
| `stroke` | `#E3DED2` | 分割线、卡片描边 |
| `text` | `#1B1B1F` | 主文字 |
| `textDim` | `#6E6A62` | 次要文字、说明 |
| `accent` | `#C62828` | 强调色（与深色一致，保持品牌辨识） |
| `ok` | `#2E9E57` | 成功 |

### 1.3 主题策略

- 切换**即时生效**，不重置编辑内容、不重建 Activity。
- 画布背景独立三档：**透明 / 与皮肤一致 / 固定色**，默认「透明」。
- 浅色皮肤下，预览画布加一圈 `stroke` 细描边，避免浅色作品"融进背景"。
- 颜色统一走 `MaterialTheme.colorScheme` + 自定义扩展，禁止硬编码 hex。

### 1.4 通用尺寸 token

| Token | 值 |
| --- | --- |
| 圆角 | 卡片 16dp / 按钮 12dp / 输入框 12dp |
| 间距 | 4 基准：4 / 8 / 12 / 16 / 24 |
| 触控区 | ≥ 44dp（滑杆拇指 24dp） |
| 字号 | 标题 20sp / 正文 15sp / 说明 12sp / 大输入 24sp |

**节奏**：微交互 150ms，面板切换 250ms，书写动画按字数自动 2.0–3.3s（成片感，不能太快）。

## 2. 全局结构

- 单 Activity，路由：`Home` / `Editor`（全屏 Modal）/ `Templates` / `Mine` / `Export` / `Settings`。
- 顶栏统一：左返回、中间标题、右 1–2 个操作。
- 编辑器为**沉浸式**：预览区占满上半屏，参数面板占下半屏，可上下拖动调整比例（默认 50:50）。

### 手势表

| 位置 | 手势 | 行为 |
| --- | --- | --- |
| 预览画布 | 单指拖拽 | 移动签名位置 |
| 预览画布 | 双指捏合 | 缩放（0.5×–3×） |
| 预览画布 | 双指旋转 | 旋转（±30°） |
| 预览画布 | 双击 | 复位居中 |
| 预览画布 | 长按 | 全屏无 UI 观赏模式 |
| 参数面板 | 上滑 / 下滑 | 展开 / 收起面板 |
| 滑杆 | 拖动 | 实时预览（低清），松手回全清 |

## 4. 参数面板详细规格（5 个 Tab）

### 4.1 字体

```
│ 字体                          │
│ ┌──┐┌──┐┌──┐┌──┐┌──┐  ›       │  横滑字体卡（卡片里用该字体显示"张三"）
│ │马││行││草││龙││黑│          │
│ └──┘└──┘└──┘└──┘└──┘          │
│ 倾斜   ▬▬▬●▬▬▬  -6°           │
│ 字重   ▬▬▬▬●▬▬  +2           │
│ 连笔   ▬▬●▬▬▬▬  30            │
```

| 控件 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| 字体选择 | 5 套（P0 内置） | 马善政毛笔楷书 | 卡片用当前名字预览 |
| 倾斜 | −20° ~ 20° | 0° | 几何 skew |
| 字重 | −3 ~ +3 | 0 | 轮廓偏移/描边加粗 |
| 连笔 | 0–100 | 20 | P1 生效，P0 置灰 |

### 4.2 颜色

```
│ 文字   [ 纯色 ][ 渐变 ]        │
│ ● ● ● ● ● ● ● ●  ＋           │  预设色板 + 自定义
│ 渐变条 ▭▭▭▭▭▭   角度 ▬▬●▬    │
│ 发光 ▬▬●▬▬ 0.15    描边 ○    │
│ 投影 ▬▬▬●▬ 0.25                │
│ ──────────────────────────    │
│ 背景   [透明][纯色][渐变][纸纹] │
│ ┌──┐┌──┐┌──┐┌──┐  ＋          │
│ │宣││皮││墨││格│               │
│ └──┘└──┘└──┘└──┘               │
```

- 渐变模式：出现颜色条（可增删色标，拖动改位置）+ 角度滑杆 + 线性/径向/角度切换。
- 自定义颜色 → 系统取色器 + "存为常用色"。
- 每个滑杆右侧显示数值，点数值可输入精确值（P1）。

### 4.3 动效

```
│ 动效                  [▶ 预览] │
│ ┌──┐┌──┐┌──┐┌──┐┌──┐          │
│ │逐││流││霓││描││入│          │
│ │笔││光││虹││光││场│          │
│ └──┘└──┘└──┘└──┘└──┘          │
│ 时长    ▬▬▬▬●▬▬  2.6s  自动  │
│ 快1.5s  自动  慢3.0s  自定义   │
│ 缓动    [线性][淡出][弹性]      │
│ 时间轴  ▬▬░░░░░░▬▬░           │
```

- 卡片可多选（多动效叠加，P1 完整支持；P0 允许选 2 个）。
- 时间轴条是缩略可视化：横轴时间，每个选中动效一行小色块。
- 拖动时长滑杆时实时重播（只播最后 40%）。
- **时长规则**：默认「自动」= `700 + 650 × 字数` ms，钳制 1500–4500（2 字≈2.0s / 3 字≈2.6s / 4 字≈3.3s）；手动拖滑杆即转「自定义」，点「自动」恢复。
- 设置页的「默认动画时长」决定新作品的初值；编辑器内改动只影响当前作品，不写回全局。

### 4.5 落款

```
│ 印章                    ○──  │
│ 形状 [方][圆][椭] [阴][阳]    │
│ 颜色 ● ● ●      文字 [签名▾]  │
│ ──────────────────────────    │
│ 日期                    ○──  │
│ 格式 [2026.11][丙辰年冬]      │
```

## 6. 状态与边界

### 6.1 状态机

```
首页(空) ──输入──▶ 编辑器(有内容)
编辑器 ──导出──▶ 导出中 ──成功──▶ 完成（提示 + 分享入口）
                     └──失败──▶ 错误条（重试 / 改尺寸）
编辑器 ──返回──▶ 首页（草稿保留）
```

### 6.2 边界清单

| 场景 | 处理 |
| --- | --- |
| 空输入点"开始设计" | 输入框抖动 + 提示"先写个名字吧" |
| 超过 8 字 | 截断到 8 字 + Toast"最多 8 个字" |
| 生僻字字体缺字 | 预览右上角角标"该字使用备用字体"，点开说明原因 |
| 竖排 8 字超出画布 | 自动缩字号至适配，参数面板显示"已自动适配" |
| 导出时切后台 | 继续后台导出，完成后系统通知 |
| 导出失败（存储不足/编码异常） | 错误条 + 重试按钮，不丢当前编辑内容 |
| 低端机性能不足 | 自动关粒子与模糊，面板顶部提示"已开启流畅模式" |
| 未开任何动效 | 仍可正常导出 PNG（静态），导出页只亮 PNG |
| 字体缺字且系统字体也无该字 | 该字显示占位方框 + 明确提示，不静默 |

## 8. 文案规范

- 按钮 2–4 个字；动词开头（"开始设计""保存到相册""重播"）。
- 提示语不用"错误""失败"开头，先说要做什么：✗"导出失败" → ✓"保存没成功，点这里重试"。
- 涉及名字的地方不出现"您的名字已上传"之类暗示（本产品不联网）。
- 全部文案进 `strings.xml`，不拼接。

## 9. 本轮已确认

| 事项 | 结论 |
| --- | --- |
| 浅色主题 | 做。深色 / 浅色 / 跟随系统，默认跟随系统；**UI 皮肤与画布背景解耦** |
| 模板分类 | 加场景维度：风格 6 类 × 场景 6 类，场景为筛选 chip；P0 扩到 24 套 |
| 动画时长 | 推荐默认「自动」：2 字≈2.0s、3 字≈2.6s、4 字≈3.3s；另配 快 1.5s / 慢 3.0s / 自定义 1–6s；设置页可改全局 |
