## 1. 产品定位

**一句话**：输入名字，实时生成一幅"会自己写出来"的艺术签名，可导出成图片、动图和手机壁纸。

- **目标用户**：需要签名图案的个人（社交头像、作品署名、文档落款、婚礼/生日礼物）、小商家（店铺招牌字、名片、logo 字）。
- **核心场景**
  1. 发朋友圈/抖音的"名字动图"，要求好看、有逼格、能一眼看出是自己名字。
  2. 做水印/头像/文档落款，要求透明底、高清。
  3. 做手机动态壁纸，要求低调、不耗电。
- **差异化**（对比市面"艺术签名设计"类 App，多为静态图片 + 固定模板 + 广告）
  1. **逐笔书写动画**：不是把静态字做淡入，而是按笔顺"写"出来。
  2. **透明底 + 高清导出**，真正能当水印用。
  3. **完全离线**，不联网、不传名字（名字是隐私）。
  4. 参数全开放：字体/颜色/材质/动效各维度可调，且能存成自己的模板。

## 2. 用户主流程

```
① 输入名字           ② 选模板 / 选字体          ③ 微调参数              ④ 导出 / 设为壁纸
 ┌──────────┐        ┌──────────────┐        ┌──────────────┐       ┌──────────────┐
 │ 键盘输入  │  ───▶  │ 20 套内置模板 │  ───▶  │ 颜色/材质/动效 │  ──▶  │ PNG/GIF/MP4  │
 │ 或粘贴    │        │ 实时预览动画  │        │ 排版/背景     │       │ 动态壁纸     │
 └──────────┘        └──────────────┘        └──────────────┘       └──────────────┘
```

关键体验要求：**任何参数改动在 150ms 内看到效果**，预览区常驻播放/重播按钮。

## 4. 功能需求

标记：**P0** = 第一版必须有；**P1** = 第二版；**P2** = 以后再说。

### F1 文字输入
- P0 单行输入，1–8 个字符；超出/空输入给明确提示。
- P0 支持中文、拉丁字母、数字、常见符号。
- P0 自动去掉首尾空格；粘贴长文本时截取前 8 字并提示。
- P1 支持两行（姓 + 名分开排版）。
- P1 生僻字处理：字体缺字时自动 fallback 到系统字体，并在参数面板标注"该字已用备用字体"（**不能静默变丑**）。

### F2 排版
- P0 横排 / 竖排切换。
- P0 字号、字距、行距、整体旋转（−30°~30°）、整体缩放。
- P0 水平/垂直居中、九宫格对齐。
- P1 基线弯曲（上弧 / 下弧 / S 形）、单字倾斜、逐字错落（大小/高低下限随机）。
- P1 连笔强度 0–100（影响相邻笔画是否桥接）。
- P2 每字单独拖拽微调。

### F3 字形引擎（核心）
- P0 内置 **3 套**中文艺术字体 + **2 套**英文花体（详见 §7.7 版权清单）。
- P0 字体加载后转成 `Path`（矢量轮廓），保证任意缩放不糊、可做描边/遮罩。
- P0 程序化变形（不改字体文件，运行时几何变换）：
  - 倾斜 (skew)、横向拉伸/压缩、笔画粗细（对轮廓做偏移/描边加粗）、圆角/锐角化。
- P1 字形前后错位（伪连笔）、拉丝（延长起笔/收笔）、字内装饰点。
- P1 字体子集化：内置字体只打包常用 3500 字 + 姓氏用字，包体从 10MB+ 降到 1–3MB。
- P2 按需下载字体包（需联网，届时单独申请权限并在设置里说明）。

### F4 颜色与材质
- P0 填充：纯色、线性渐变、径向渐变、角度渐变；多段渐变色标可增删拖动。
- P0 质感：外发光（颜色/半径/强度）、投影（偏移/模糊/颜色）、描边（粗细/颜色）。
- P0 背景：透明、纯色、渐变、内置纸纹（6 张）。
- P1 金属高光（高光带 + 渐变）、霓虹（双层 glow）、内发光、图片填充。
- P1 印章：矩形 / 圆形 / 椭圆，阴文 / 阳文，预设红色系，可加落款日期（如"丙午年"）。
- P1 落款三件套（**各自独立开关，互不影响**）：
  - 印章（名章）：形状 / 阴文阳文 / 红色系 / 文字内容，可加顺时针旋转与轻微随机偏移，模拟真盖章
  - 落款日期：`2026.11` 与 `丙辰年冬` 两种写法，位置默认右下
  - 第二行文字：公司名 / 头衔 / 英文名，触发双行排版（继承第一行字体与配色，可单独调字号）
- P2 玻璃/水波扭曲（AGSL RuntimeShader，仅 Android 13+）。
- P0 色盘支持保存自定义色板（每人一套常用色）。

### F5 动效引擎（详见 §5 动效详表）
- P0 逐笔书写、流光扫过、霓虹呼吸、描边流光、入场动画。
- P0 每个动效可调：时长、延迟、缓动曲线、循环与否。
- P0 时长默认「**自动**」：`时长 = 700 + 650 × 字数` ms，钳制 **1500–4500ms**（2 字≈2.0s、3 字≈2.6s、4 字≈3.3s）；另提供 快 1.5s / 慢 3.0s / 自定义 1.0–6.0s。设置页可改全局默认，编辑器内可单独覆盖。
- P0 播放控制：自动播放、重播、暂停（导出时用固定时钟逐帧驱动，保证可复现）。
- P1 墨迹晕开、粒子（星点/金粉）、印章按压、多动效叠加时间轴。
- P2 飞白/干笔纹理、3D 倾斜视差、待机循环（壁纸用）。
- P0 **降级策略**：低端机/导出前自动关粒子与模糊，保证不卡死。

### F6 模板与预设
- P0 内置 **24 套**模板（6 风格 × 4），每套 = 字体 + 颜色 + 材质 + 动效 + 排版的完整参数组合，一键套用。
- P0 模板双维度分类：**风格**（水墨/霓虹/金属/极简/可爱/英文花体）× **场景**（通用/婚礼/生日/商务/节日/纪念）。场景是筛选 chip，一个模板可挂多个场景标签。
- P0 套用后所有参数可继续微调，不锁死。
- P1 用户把当前参数存成"我的模板"（命名 + 缩略图），可删除、可复制。
- P1 收藏模板。
- P2 模板导入/导出为 JSON 文件（方便分享）。

### F7 画布交互
- P0 双指缩放 / 旋转画布，单指拖动，双击复位。
- P0 预览区右下角：播放/暂停、重播、一键居中。
- P0 参数面板滑杆拖动时用低清预览（720p），松手后回全清。
- P1 撤销 / 重做（至少 20 步）。
- P1 长按预览区进入全屏无 UI 观赏模式。

### F8 导出与分享
- P0 PNG：透明底 / 带背景可选；尺寸预设**按导出优先级排序**：① 1080×1920（9:16 动图/故事）② 1080×1080（透明水印/方形）③ 1080×2400（壁纸）④ 512×512（头像）⑤ 自定义至 4096；保存到相册（MediaStore）。
- P0 水印：默认关闭，可开（右上角小字"由 XX 签名生成"）。
- P0 系统分享（`ACTION_SEND`）。
- P1 MP4（H.264，30/60fps，时长跟随动画）——**动态主推格式**，朋友圈/抖音首选。
- P1 GIF（25/30fps，循环）——注意 GIF 透明只有 1 bit，半透明会变硬边，导出前提示。
- P2 透明动图（APNG / 动态 WebP）、逐帧序列图导出。
- P2 签名直接用作图片水印的"批量加签"。

### F9 动态壁纸
- P2 `WallpaperService.Engine` 实现，签名居中或右下角，适配竖屏。
- P2 帧率 30fps，静止 10 秒后降到 15fps 省电；提供"电量低于 20% 暂停动画"开关。

### F10 本地数据（无账号）
- P0 最近使用、当前编辑状态自动保存（杀进程后恢复）。
- P1 收藏、我的模板、导出历史（仅记录路径与缩略图）。
- P0 数据全部存本地（DataStore/文件），不上传，不申请网络权限。

### F11 临摹练习（P2）
- P2 进入"练习模式"：逐笔提示笔顺（半透明引导轨迹 + 笔尖指示），用户在屏上跟写。
- P2 跟写结束给出覆盖率评分与自己的笔迹回放，可保存为专属签名（作为 P2 手写录入的过渡）。
- P2 独立入口，不进入签名生成主流程。

### F12 国际化预留
- P0 全部 UI 文案走 `strings.xml`，禁止硬编码；中文为默认语言。
- P0 文案不做字符串拼接、不依赖中文语序，为后续英文版留空间。
- P2 补英文翻译 + 英文排版（英文花体模板单独一组）。

## 7. 技术方案

### 7.1 技术栈
- **Kotlin 2.x + Jetpack Compose (Material 3)**，单 Activity + Compose 导航。
- 渲染：Compose `Canvas`（P0）→ 性能不足的动效（模糊/粒子/大画布）改用 `SurfaceView` + AGSL `RuntimeShader`（API 33+），低版本用 OpenGL ES 3.0 或纯 Canvas 兜底。
- 文字转路径：`android.graphics.Paint.getTextPath()` → `android.graphics.Path`。
  **这是整个方案的地基**：有了矢量轮廓，缩放、描边、渐变填充、遮罩揭示全部自由。
- 动画：自研轻量时间轴（`Choreographer` 驱动），导出时接固定时钟（`frameIndex * 1000/fps`），保证"预览 = 导出"完全一致。
- 状态：Compose State + `ViewModel`；持久化用 DataStore（JSON 序列化）。
- 最低依赖，不引入重型 2D/游戏引擎。

### 7.2 渲染管线（关键设计）

**核心架构决策：字形层与笔顺层解耦。**

```
字符 ──▶ ① 字形层：字体轮廓 Path（决定"长什么样"）
      └─▶ ② 笔顺层：中心线 Path 序列（决定"怎么写出来"）
                │
         ③ 合成：沿中心线推进圆头笔尖遮罩 ∩ 字形层 → 已写部分
                │
         ④ 着色：渐变/发光/描边/纸纹 作用于"已写部分"
                │
         ⑤ 合成到画布 + 背景 + 印章 + 粒子
```

优点：**换字体不影响动画**，同一套笔顺数据可驱动 3 套不同字体；反之换动效也不用重做字形。

### 7.3 笔顺数据方案（最大技术风险，需先验证）

| 方案 | 做法 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- | --- |
| A 现成笔顺库 | 用 Make Me a Hanzi / hanzi-writer 的笔画轮廓 + 中线数据（约 9000 字） | 开箱即用，笔顺权威 | 数据源自 Arphic 字体，许可证要求保留声明并对衍生物开源，商用需法务确认；且形状是标准楷体，与艺术字体不匹配 | ❌ 不直接打包 |
| B 自动骨架化 | 字形轮廓 → 二值化 → 细化 (thinning) → 找分支点/端点 → 切分成笔画 → 贪心排序成书写顺序 → 平滑成贝塞尔 | 任意字体任意字都能用，零版权风险，换字自动适配 | 复杂字可能切错、顺序怪；需调参 | ✅ **P0 主方案** |
| C 手工路径 | 每个字手工/半自动配置几条"书写轨迹"，沿轨迹推进遮罩 | 最省事、草书效果自然、完全可控 | 覆盖字数有限，工作量随字数线性增长 | ✅ **兜底 + 高频字精修** |

**落地策略**：
1. P0 用 B 自动生成，对**高频姓氏 Top 100 + 常用字**做一次离线预计算，缓存成资产文件（每字约 2–8KB，很小），运行时直接读，不占 CPU。
2. 预计算时人工抽检校正 Top 100 姓氏，质量差的字改用 C 手工轨迹。
3. 未命中缓存的字运行时走 B 兜底；再失败则退化为"轮廓整体渐显"（保证不崩）。
4. 数据格式：`{ char, strokes: [ { d: "M..C..", medians: [x,y...] } ] }`。

### 7.4 动效实现要点
- 逐笔书写：`PathMeasure` 取中心线，按进度取一段 → 扩成圆头笔尖形状 → `clipPath`/`Xfermode` 只显示字形层里的部分。笔尖直径随手写速度变化 → 自然的粗细变化。
- 流光：`LinearGradient` 做 `Shader`，动画平移 `shader.localMatrix`；成本低，任何机型可跑。
- 霓虹：文字先画 `Paint.maskFilter = BlurMaskFilter` 两遍（外晕 + 内芯），alpha 正弦调制。
- 粒子：对象池复用 `Particle`，避免 GC；上限按设备性能自动给（低端 50 / 中端 150 / 高端 300）。
- 所有动效 **参数化 + 无副作用**，方便导出时逐帧重放。

### 7.5 导出实现
- PNG：离屏 `Bitmap` 同管线重绘 → `MediaStore.Images` 写入相册。
- MP4：离屏逐帧渲染 → `Surface` 输入 `MediaCodec`(H.264) → `MediaMuxer` 封装；30fps 默认。
- GIF：逐帧 → 调色板量化（NeuQuant）+ LZW 编码（自写约 300 行，或引轻量库）；逐帧延迟 33ms。
- 进度：导出在后台线程 + 进度回调，可取消。

### 7.6 动态壁纸（P2）
`WallpaperService` → 独立 `Engine` 渲染循环，复用同一套渲染管线；锁屏单独绘制避免耗电；限帧 30/15fps。

### 7.9 本机环境现状与落地路径

当前 DSH 环境（Android 上的 Ubuntu proot）**没有 java / gradle / Android SDK**；磁盘剩 31G、内存 15G，装得下。

| 路径 | 做法 | 耗时 | 风险 |
| --- | --- | --- | --- |
| **B 先做 Web 原型（建议先走这条）** | 用同一套参数模型 + Canvas 写一个网页版，手机浏览器直接打开看动效 | 1–2 天 | 与最终 Android 渲染有细微差异，需二次移植 |
| **A 直接编译 APK** | `apt install openjdk-17-jdk` → 下载 Android cmdline-tools → `sdkmanager "platforms;android-35" "build-tools;35.0.0"` → Gradle 编译 debug APK | 首次 3GB+ 下载，编译慢 | proot 下 Gradle 可跑但慢；**proot 里没有 adb 无法直装到手机，只能把 APK 文件放出来手动安装** |

**建议**：先 B 验证 3 套字体 + 5 个动效的观感（成本最低、反馈最快），确认方向后再走 A 出真 APK。

## 9. 验收标准（P0 完成定义）

1. 输入 2–4 个中文字，任选 3 套字体，逐笔书写动画可完整播放，**无断笔、无漏笔、无倒笔明显穿帮**（Top 100 姓氏随机抽 20 个全部通过）。
2. 3 套字体 × 8 套配色 × 5 个动效可自由组合，实时预览 ≥ 50fps，切换 ≤ 150ms。
3. 24 套内置模板一键套用，效果与设计稿一致；场景筛选结果正确。
4. 导出 1080×1080 PNG（透明底）后，发到微信朋友圈背景无白边、边缘不糊。
5. 切飞行模式，全部功能（除字体包下载）可用，无一次崩溃。
6. 杀进程后重新打开，上次编辑内容完整恢复。
7. 中端机（骁龙 7 系 / 天玑 8000 级）冷启动 ≤ 1.5s，包体 ≤ 40MB。

## 11. 风险与对策

| # | 风险 | 影响 | 对策 |
| --- | --- | --- | --- |
| 1 | 自动骨架化笔顺效果差 | 核心卖点不成立 | 解耦架构（换一个笔顺引擎不影响其它）；高频字人工校正；兜底"轮廓渐显" |
| 2 | 中文字体包体过大 | 上架受限 | 子集化 + 字体包按需下载 |

| 4 | 生僻字缺字 | 用户打出自己名字但显示异常 | 系统字体 fallback + 明确提示 |
| 5 | GIF 体积大、不支持半透明 | 导出效果差 | 动图主推 MP4；GIF 仅短视频用并提示限制 |
| 6 | 字体版权 | 法律风险 | 只用 OFL/免费商用字体，内置许可页 |
| 7 | 动态壁纸耗电 | 用户卸载 | 限帧 + 静止降帧 + 省电开关 |
| 8 | 本机无 Android 构建环境 | 出不了 APK | 先 Web 原型验证，再按 §7.9 路径 A 装环境 |
